Deliverable (plan row 3.1): a point-mass flight model along the same waypoint path with the threat's limits from `UasSpec`: `maxTurnRateDegS`, `climbRateMps`, `maxAccelMps2` (null means unlimited for that term), `cruiseSpeedMps` and `maxSpeedMps` as today, plus wind drift from `EnvironmentSpec.windSpeedMps` and `windFromDeg` when `environment.apply` is on. The threat follows the waypoints with a turn of bounded rate at each vertex (a fillet arc), accelerates from the path start at the acceleration limit up to the path speed, and drifts with the wind vector as a ground-speed offset (the threat holds heading and airspeed; the ground track shifts). Altitude stays a scalar (the climb limit bounds any altitude change the path already models; if the path has no altitude change, record the climb limit as unused, do not invent a climb).

Where it plugs in: `posAtTime` in `geo.ts` is the truth position for the sweep (`sim.ts`, `tracks.ts`, `trackState.ts`, `trialTrackState.ts`, `intercept.ts` call it). Keep `posAtTime`'s signature and behaviour for callers that pass no limits; add the limited path through a new function in `flight.ts` that `tracks.ts` (and so the sweep) selects when the threat has limits and the `noFlightLimits` switch is off. Callers outside your set that need to switch to the new function: stop and report the file and line; the orchestrator wires them. Time of flight along a limited path may differ from the unlimited path; the arrival time the assessments read comes from the same function, so it stays consistent.

Stop condition: a threat with no limits (every new field null) reproduces `posAtTime` bit for bit at every sample time of both golden fixtures; a limited turn matches a hand-derived arc (radius V / omega, the arc length and the exit point computed in the test comment); with wind the ground track offset after t seconds equals the wind vector times t; `flight.verify.test.ts` checks one published figure (a DJI Mavic 3 or Matrice descent, ascent or max tilt figure from the seed provenance) reproduces the seed value. Validation tier: `analytic`.
